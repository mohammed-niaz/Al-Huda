Connection to GitHub (one-time setup on this phone)
  1. On github.com go to Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Al-Huda.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Copy the token and paste it below. It is stored only on this device.
